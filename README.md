# DreamStoneHR — HR Health Check

This repository contains the **HR Health Check** web experience for [DreamStoneHR](https://www.dreamstonehr.com.au).

The interactive app lives in [`hr-health-check/`](./hr-health-check/). Source PDF exports of the previous Agolix assessment are kept in the repo root for content reference.

```bash
cd hr-health-check
npm install
npm run dev
```
